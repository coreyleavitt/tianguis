tianguis

an open-air market for Nim packages — content-addressed, attestation-bearing, fork-resistant

tianguis is a Nim package registry built on three commitments:

  • content addressing. every package version has a sha256 of its source tree. fetch + recompute = verify.
  • Sigstore attestation. every entry is signed (cosign keyless via Sigstore). searchable in Rekor.
  • no human merges. publishing is automated via a stateless dispatch endpoint. tag-push to installable in ~60 seconds.

works with milpa, the Nim resolver that replaces nimble's SAT solver.
